COMMAND REFERENCE

PSX CLI Commands

This is the complete list of commands currently provided by PSX CLI. Each command handles one focused check and prints the result in your terminal.

help General

Help

Shows all available commands and their purpose.

psx help
version General

Version

Displays the current PsX version.

psx version
about General

About

Provides information about the tool itself.

psx about
sysinfo System

System Information

Shows operating system, distribution, kernel, CPU, and RAM information.

psx sysinfo
date System

Date

Displays the current system date and time.

psx date
memory System

Memory

Shows information about system memory.

psx memory
disk System

Disk

Shows all detected disks on your device.

psx disk
partition System

Partition

Shows all partitions on your system.

psx partition
uptime System

Uptime

Shows the system uptime.

psx uptime
network System

Network

Shows network information, including available interfaces and addresses.

psx network
weather Utility

Weather

Shows the current weather, including the location, condition, temperature, and feels-like temperature. It requires an internet connection.

psx weather
