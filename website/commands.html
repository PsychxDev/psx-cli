COMMAND REFERENCE

PSX CLI Commands

Explore the commands available in PSX CLI. Each command provides a simple way to access useful system information directly from your terminal.

help General

Help

Displays information about available PSX commands and how to use the CLI.

psx help
version General

Version

Displays the currently installed version of PSX CLI.

psx version
about General

About

Displays information about PSX CLI and the project.

psx about
sysinfo System

System Information

Displays general information about the current system and environment.

psx sysinfo
date System

Date

Displays the current system date and time.

psx date
memory System

Memory

Displays information about system memory usage.

psx memory
disk System

Disk

Displays information about available disk space and storage usage.

psx disk
partition System

Partition

Displays information about the system's disk partitions.

psx partition
uptime System

Uptime

Displays how long the system has been running since the last boot.

psx uptime
network System

Network

Displays useful information about the system's network configuration.

psx network
