COMMAND REFERENCE

PSX CLI Commands

This is the complete list of commands currently provided by PSX CLI. Each command handles one focused check and prints the result in your terminal.

helpGeneral

Help

Shows all available commands and their purpose.

psx help
versionGeneral

Version

Displays the current PsX version.

psx version
aboutGeneral

About

Provides information about the tool itself.

psx about
sysinfoSystem

System Information

Shows operating system, distribution, kernel, CPU, and RAM information.

psx sysinfo
dateSystem

Date

Displays the current system date and time.

psx date
memorySystem

Memory

Shows information about system memory.

psx memory
diskSystem

Disk

Shows all detected disks on your device.

psx disk
partitionSystem

Partition

Shows all partitions on your system.

psx partition
uptimeSystem

Uptime

Shows the system uptime.

psx uptime
networkSystem

Network

Shows network information, including interfaces and addresses.

psx network
domainNetwork

Domain

Displays information about a domain.

psx domain
pingNetwork

Ping

Tests network connectivity to a host.

psx ping
dnsNetwork

DNS

Checks DNS resolution.

psx dns
todoUtility

Todo

Manages todo items.

psx todo
profileUtility

Profile

Displays a system profile.

psx profile
quickUtility

Quick Check

Runs a quick system check.

psx quick
healthSystem

Health

Checks system health.

psx health
clearspaceSystem

Clear Space

Finds files and locations that may be cleaned up.

psx clearspace
trackUtility

Track

Tracks system activity.

psx track
weatherUtility

Weather

Shows the current weather, including location, condition, temperature, and feels-like temperature.

psx weather
