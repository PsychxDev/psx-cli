PSX CLI Documentation

Learn how to install, use, and contribute to PSX CLI. Everything you need to get started is here.

Installation

PSX can be installed globally using pipx. This keeps PSX isolated while making the psx command available from any terminal.

pipx install psx-sys

Requirements

  • Linux
  • Python 3.10 or newer
  • pipx

First Run

After installation, run PSX directly from your terminal:

psx

You can also run individual commands directly. See the Commands page for the complete command reference.

Basic Usage

PSX is designed to provide useful system information through simple terminal commands.

psx <command>

Output

PSX displays information directly in the terminal using a clean and readable format.

Project Structure

PSX follows a modular Python project structure. Commands are organized separately from the main application logic. 

psx-cli/
├── psx/
│   ├── commands/
│   ├── __init__.py
│   └── main.py
├── pyproject.toml
├── README.md
└── LICENSE
