PSX CLI Documentation

Install PSX, run your first command, and find the reference pages for its system checks.

Installation

Install PSX with pipx. This keeps it isolated from other Python packages while making the psx command available from your terminal.

pipx install psx-sys

Requirements

  • Linux
  • Python 3.10 or newer
  • pipx

First Run

After installation, ask PSX for its available commands:

psx

You can then run individual commands such as psx sysinfo or psx memory. See the Commands page for the full reference.

Basic Usage

PSX follows a simple pattern: prefix a command with psx and read the result directly in the terminal.

psx <command>

Output

Output is printed in the terminal so it can be read, copied, or used in the next step of your workflow.

Project Structure

PSX uses a modular Python structure. Command implementations are kept separate from the main application logic so individual checks remain easy to inspect. 

psx-cli/
├── psx/
│   ├── commands/
│   ├── __init__.py
│   └── main.py
├── pyproject.toml
├── README.md
└── LICENSE
