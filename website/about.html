About the project

About PsX

PsX is a Python command-line tool for checking common Linux system details from one consistent interface.

What PsX does

PsX provides commands for system information, memory, disks, partitions, uptime, network details, date and time, and weather. Each command is intended to answer one small question.

Why it exists

The project keeps these checks together so you do not need to remember a different command for every basic system detail. It does not replace standard Linux tools; it gives common checks one familiar entry point.

Open source

PsX is open source. You can inspect the implementation, report problems, and change the project when its defaults do not fit your workflow.
